# Low Crane Dronehacks

A blank Astro site deployed to GitHub Pages.

Requires Node.js 22.23.4 or newer (Node.js 24 recommended) and pnpm.

```sh
pnpm install
pnpm dev
```

The home page is in `src/pages/index.astro`. Pull requests to `main` run CI; commits to `main` deploy the built site to GitHub Pages.
